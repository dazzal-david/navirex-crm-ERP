# Navirex CRM roadmap

This roadmap prioritizes lead operations for Navirex and the Navitrace dMRV platform.

## Delivered

- Lead-focused dashboard without revenue metrics.
- Status totals for every lead stage.
- Lead intake, source, entity, attention, and activity insights.
- Wider Navirex navigation with operational shortcuts.
- Personalized welcome message and route loading screen.
- Existing website form collection surfaced under Connections.
- Website form submissions create deduplicated lead-board records.
- Secured lead intake API for websites and external systems.
- Safe repeat imports for Zoho lead exports.
- Meta OAuth, page selection, webhook verification, and manual lead synchronization.
- Gmail and Microsoft email sending from lead records.
- WhatsApp Cloud API text and template sending from lead records.
- Communication activity logging for successful email and WhatsApp sends.
- Connection setup pages for lead intake, Zoho, Meta, and WhatsApp.
- Unified lead inbox for email, WhatsApp, and internal notes.
- Reusable email and WhatsApp templates with active-state controls.
- Secure inbound webhooks for lead and inbound-message collection.
- Lead-created automation triggers for manual, webhook, Meta, webform, and Zoho sources.
- Approved-template automation actions with immutable deployment permissions.
- Founder, Superadmin, Manager, and Staff workspace roles.
- Staff directory and employee profile records.
- Employee reimbursement requests with manager approval and paid states.
- Employee self-service portal with visible reimbursement status.

## Priority 0

- Extend Zoho migration to contacts, companies, notes, and activities.
- Add provider delivery events and email reply tracking.
- Add WhatsApp consent tracking and conversation history.

## Priority 1

- Add automation triggers for stage changes, assignments, and inactivity.
- Add response-time, source-conversion, assignment, and aging reports.
- Add calls to the unified communication timeline.
- Add configurable lead routing by entity, source, geography, and owner capacity.

## Priority 2

- Add department-specific permission presets beyond the four core roles.
- Add audit exports, retention policies, and integration health monitoring.
- Add campaign attribution and carbon-project interest segmentation.

## Integration prerequisites

- Meta Business account, app, page access, lead permissions, and a public webhook URL.
- WhatsApp Business account, approved sender, templates, and consent policy.
- Email provider authorization with sending and event webhook access.
- Zoho export or authorized API credentials for migration testing.
